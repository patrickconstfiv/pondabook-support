# pondabook-support

静态开发者支持页仓库。

当前站点内容：

- 开发者支持邮箱
- 英文 / 简体中文切换
- 产品图片与简洁介绍
- 已确认产品的 App Store 入口

资源说明：

- 页面主文件：`index.html`
- 产品图片目录：`assets/apps`

当前已接入图片：

- `PondaBook.png`
- `SeaNote.png`
- `Cookey.png`
- `CutCat.jpg`
- `BeaverValley.png`

维护原则：

- 页面保持简洁，避免冗长说明
- 多语言文案统一维护在 `index.html` 内的 `translations`
- 未确认的产品信息不编造，优先保留名称、图片和联系入口
